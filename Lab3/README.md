# COSC 645 Lab 3: Person Name Extraction

## Overview

This project was completed for COSC 645: Data Mining at Frostburg State University. The purpose of the lab is to explore a simple approach for extracting possible person names from text using Python, regular expressions, and heuristic rules.

The program processes the first 10,000 sentences from the BNC Baby corpus and identifies text patterns that may represent person names.

## Dataset

The lab uses sentences from the BNC Baby corpus, which is a sample of the British National Corpus (BNC). Each record contains a sentence number followed by the English sentence.

For this project, only the first 10,000 sentences are processed.

## Approach

The program uses Python regular expressions and capitalization-based heuristics to identify possible person names.

Three primary patterns are used:

1. Two- or three-word sequences containing capitalized words, such as `Roland Franklin` or `Frank Kane`.
2. Names associated with titles such as `Mr`, `Dr`, `Professor`, `Sir`, or `Lord`.
3. Uppercase name patterns commonly found in newspaper bylines, such as `FRANK KANE`.

A simple filtering step is also used to remove some phrases that are more likely to represent organizations or other non-person entities.

## Results

The program processed 10,000 sentences and identified 6,467 possible person-name matches.

Examples of successful extractions include:

- Roland Franklin
- Frank Kane
- Sir James Goldsmith
- John Moore
- Anthony Preece
- Andrew Palmer
- David Palmer
- Larry Black
- Al Checchi

The extracted results are saved to `extracted_person_names.txt`.

## Limitations

Because the program relies on capitalization and pattern-based heuristics, the results contain both false positives and false negatives.

For example, phrases such as `Big Bang`, `New York`, and `Federal Aviation Act` may be incorrectly identified as person names because they follow similar capitalization patterns.

The same person may also appear in multiple forms. For example, `Roland Franklin`, `Mr Franklin`, and `Franklin` may refer to the same individual.

These limitations demonstrate the difficulty of identifying named entities using simple text patterns without additional contextual or linguistic information.
