# Cancer Gene Expression Classification

## COSC 645 - Data Mining
Frostburg State University

## Project Overview
This project explores the use of machine learning to classify
cancer types using high-dimensional gene-expression data.

## Research Question
How effectively can machine-learning algorithms classify
cancer types using high-dimensional gene-expression data,
and how does dimensionality reduction affect model performance?

## Methods
- Exploratory Data Analysis
- Data Preprocessing
- Principal Component Analysis (PCA)
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Support Vector Machines (SVM)
- Model Evaluation and Comparison

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
